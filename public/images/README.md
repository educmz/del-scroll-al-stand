# Imágenes del inicio

Coloca aquí los archivos originales, con estos nombres exactos:

- `logo.png`: logotipo de "Del Scroll al Stand" para la barra de navegación. Se recomienda PNG con fondo transparente (idealmente 600 × 450 px o mayor).
- `feria-portada.png`: imagen principal de la feria situada a la derecha de la portada. Se recomienda PNG (idealmente 1400 × 1000 px o mayor).

La web los carga desde `/images/`, usando `import.meta.env.BASE_URL` para que funcionen correctamente tanto en Vite local como en GitHub Pages.

No se incluyen imágenes provisionales externas. Los espacios se completarán al añadir los archivos.
